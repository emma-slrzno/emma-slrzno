# 👋 Hi there

I'm **Emma Solórzano Hernández Jáuregui**, a **Data Analyst** who turns raw data into business decisions. I work with Python, SQL and Tableau, and I like asking one question first: *what decision will this analysis support?*

📍 Mexico · 🌎 Bilingual projects (ES/EN)

# 🔍 What I do

- 🧹 Clean and validate messy data (duplicates, sentinel values, impossible dates)
- 📈 Analyze profitability, conversion funnels and cohort retention
- 🧪 Design and read A/B tests with the right statistical tests
- 📊 Communicate findings through interactive Tableau dashboards
- 💡 Turn results into clear recommendations, with their limitations stated honestly
